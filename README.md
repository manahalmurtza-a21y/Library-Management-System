# 📚 Library Management System (Python OOP)

A console-based Library Management System built with Python using Object-Oriented Programming (OOP) concepts. This project manages student records and book issuances efficiently.

---## 🌟 Key Features- **Class-Based Architecture:** Organized using `Student` and `Library` classes.- **Dynamic Book Issuance:** Allows issuing multiple books at once to a single student.- **Fast Record Mapping:** Uses dictionary lookups (`roll_no` -> `Student`) for quick data retrieval.- **Input Validation:** Prevents program crashes when invalid numbers or choices are entered.- **Daily Summary Generator:** Produces formatted reports of total students and issued books.

---## 🛠️ Tech Stack & Requirements- **Language:** Python 3.x- **Development Tools:** PyCharm / Thonny / VS Code
